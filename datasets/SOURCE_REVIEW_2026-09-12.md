# Source review — 12 กันยายน 2569

ตรวจข้อมูล admission dataset ปีการศึกษา 2570 และแหล่งอ้างอิง ณ วันที่ 12 ก.ย. 2569
ตรวจลิงก์อัตโนมัติเวลา 19:21 น. ตามเวลาไทย

## สรุป

- Dataset มี 9 มหาวิทยาลัย, 17 วิทยาเขต/พื้นที่, 87 หลักสูตร, 137 โครงการ
  (ทางการ 134 / draft 3), 179 คู่โครงการ–หลักสูตร, 179 เกณฑ์, 625 เหตุการณ์
  และ 8 ปฏิทินกลาง
- ตรวจ URL ที่ไม่ถูกยกเว้น 109 รายการ: เปิดได้ 94, ผิดพลาด 15, และ 91 รายการมีวัน
  ตรวจเกิน 7 วัน สถานะเกิน 7 วันเป็นเพียงสัญญาณให้ตรวจซ้ำ ไม่ได้แปลว่าข้อมูลผิด
- รายงานรอบก่อนที่ใช้เทียบ hash ไม่มีอยู่ใน workspace จึง `changed=0` จากรอบนี้ไม่ได้
  ยืนยันว่าไม่มีเว็บเปลี่ยน
- ตรวจเนื้อหาจากต้นทางได้และเทียบกับรายการใน dataset: KU และ CMU ตามรายการด้านล่าง
  ไม่พบข้อเท็จจริงที่ต้องแก้ใน scope ที่ตรวจ

  ที่กำแพงแสน จำนวนรับและเกณฑ์ที่อ่านได้ตรงกับ dataset

## แหล่งที่ยังต้องติดตาม

รายการ 15 URL ที่ตรวจไม่สำเร็จ ไม่ได้ถูกใช้เป็นหลักฐานให้แก้ข้อมูล:

- สจล. 6 URL ตอบ 404: PDF ข่าวเก่า 4629, 4630, 4632, 4633, 4640 และลิงก์เก่า
  หน้า Portfolio ของคณะเทคโนโลยีสารสนเทศ
- มหิดล 2 URL: หน้า admission วิศวกรรมตอบ 403 และหน้า campus ตอบ 403
- จุฬาฯ 1 URL: PDF ของคณะพาณิชยศาสตร์และการบัญชีตอบ 404
- มช. 1 URL: หน้า campus timeout
- มศว. 5 URL: หน้า admission และ PDF ติดข้อจำกัด TLS `DH_KEY_TOO_SMALL`; ยังสรุปไม่ได้ว่า
  ประกาศหรือเว็บไซต์ถูกถอดออก

ให้ใช้หน้า admission ทางการที่ยังเปิดได้เป็นจุดเริ่มต้นค้นประกาศทดแทน แล้วจึงแก้ข้อมูล
เป็นรายโครงการเมื่อมีหลักฐานอ่านได้ ห้ามคัดลอกเกณฑ์ปีก่อนหรือเดาวันสมัครมาแทน

## การเปลี่ยนแปลงใน repository

- ตั้ง `checked_at` ของ dataset และ source audit เป็น `2026-09-12T19:20:01+07:00`
- อัปเดต `source_checked_at` เฉพาะปฏิทิน KU/CMU และหน้ารายโครงการที่ตรวจเนื้อหา
- เพิ่มหน้า CMU รหัส 703/704/706 ลงในรายการ audit เพื่อให้รอบตรวจถัดไปติดตามตรงกับ URL
  ที่โครงการใช้จริง
- สร้าง `seed_tcas70.sql` และไฟล์แบ่งส่วนใหม่จาก JSON ล่าสุดแล้ว
- ไม่เปลี่ยนเกณฑ์รับสมัครหรือวันสมัคร เพราะไม่มีข้อเท็จจริงใหม่ที่ยืนยันได้จากหน้าที่ตรวจ
- ยังไม่ได้รัน seed ใน Supabase หรือ push ขึ้น GitHub
