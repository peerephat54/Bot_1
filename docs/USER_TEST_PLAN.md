# แผนทดสอบกับนักเรียนจริง

ยังไม่ควรอ้างว่าทดสอบกับผู้ใช้จริงแล้วจนกว่าจะมีผู้เข้าร่วม 10–20 คนและบันทึกผลครบ แผนนี้ออกแบบให้เก็บข้อมูลโดยไม่เก็บ Discord ID หรือข้อมูลส่วนตัวที่ไม่จำเป็น

## กลุ่มผู้ทดสอบ

- นักเรียน ม.6 หรือผู้สมัครเทียบเท่า 10–20 คน
- แบ่งผู้ที่รู้มหาวิทยาลัยเป้าหมายและผู้ที่ยังไม่รู้สายเรียน
- ขอความยินยอมก่อนทดสอบ และใช้รหัสผู้ทดสอบแทนชื่อจริง

## งานที่ให้ทำ

1. เปิด `/start` แล้วหาหลักสูตรที่เหมาะกับตนเองโดยไม่ใช้คำสั่งช่วยเหลือ
2. ใช้ `/grade_check` เลือกสาย กรอก GPAX และเปิดผลของมหาวิทยาลัยหนึ่งแห่ง
3. จากการ์ดโครงการ บอกวันปิดรับสมัคร วันสัมภาษณ์ และเอกสารที่ต้องเตรียม
4. อธิบายความหมายของสถานะ ผ่าน / ไม่ผ่าน / ต้องตรวจเพิ่ม / ไม่มีข้อมูล
5. เปิดประกาศทางการจากการ์ด

## ตัวชี้วัด

| ตัวชี้วัด | วิธีวัด | เป้าหมายเริ่มต้น |
|---|---|---|
| เวลาถึงคำตอบแรก | วินาทีตั้งแต่เริ่มจนเห็นวันปิดรับหรือเกณฑ์ | ลดลงเมื่อเทียบกับการค้นเอง |
| งานสำเร็จ | ทำภารกิจครบโดยไม่ต้องบอกเส้นทาง | อย่างน้อย 80% |
| จุดสับสน | บันทึกเมนู/คำศัพท์/ปุ่มที่กดผิด | หา top 3 จุดเพื่อแก้ |
| เปิดแหล่งทางการ | จำนวนผู้ที่กดลิงก์ประกาศ | ใช้ตรวจความน่าเชื่อถือ |
| ความมั่นใจ | ให้คะแนน 1–5 ก่อนและหลังใช้ | หลังใช้สูงขึ้น |
| กลับมาใช้อีก | นัดให้ลองซ้ำหลัง 3–7 วัน | วัด retention เบื้องต้น |

## แบบฟอร์มบันทึกผล

ใช้แถวหนึ่งต่อหนึ่งภารกิจ โดยไม่บันทึก Discord ID:

```text
tester_code,task,time_to_first_answer_sec,task_success,wrong_clicks,backtracks,official_source_opened,confusion_point,confidence_before,confidence_after,comment
T01,start_recommendation,,,,,,,,,
T01,grade_check,,,,,,,,,
T01,find_deadline,,,,,,,,,
```

ผลจากไฟล์นี้ควรสรุปเป็นค่า median ของเวลา, success rate, top confusion points และค่าเฉลี่ยความมั่นใจก่อน/หลัง แล้วใส่วันที่และจำนวนผู้ทดสอบใน README ก่อนนำเสนอกรรมการ
